TCG Tournament Manager 0.2.3 for Windows: run One Piece, Pokémon and Magic: The Gathering
(Modern and Commander) tournaments for a club on one PC, without internet.

## What it does

- One-on-one Swiss tournaments for One Piece, Pokémon and Magic Modern, with pairings that
  avoid rematches whenever possible and a bye for odd numbers of players.
- Magic Commander events in pods of three or four, with check-in, drops, byes, result
  corrections and an audit history.
- A fixed number of rounds per tournament, and "End tournament early" to stop one and
  keep it as a read-only record.
- A saved round clock with start, pause, resume and reset. When time runs out it shows a
  notice; it never decides results.
- Standings with tiebreakers per game, final placings saved when a tournament finishes.
- A player directory with permanent IDs, same-name handling and tournament history.
- Printed pairings and table or pod signs (or PDF), standings as PDF or CSV.
- Database backup export and a diagnostic report from Settings.

## Changes since 0.2.1-preview

- Pokémon's second tiebreaker (Opp Opp Win%) is now worked out; it was always 0 before.
- One-on-one pairing no longer repeats a match when a round without a rematch exists.
- A result and the standings that follow it are saved together, and so are a new player
  and their registration.
- Players can no longer be removed from a tournament once it has started, and a
  tournament can only be finalized in its last round.
- Names typed with characters such as `<` are always shown as typed.
- Exported standings CSV files can no longer be read as spreadsheet formulas.
- Database backup export no longer loses an earlier backup when a copy fails, and
  includes every saved change.
- Fixed a crash when a page was replaced while one of its questions was still open.
- Built with Qt 6.11.3, which fixes a Qt SVG security issue (CVE-2026-6210) in the Qt
  6.10 version used before.
- Players page and round pages respond faster with large player lists.
- Versions are now plain numbers; "preview" is no longer used.

Your existing data is kept. The first start updates the database format and saves a
copy in the backups folder before doing so.

## Install

1. Download `TcgTournamentManager-0.2.3-win64.zip` below.
2. Check its SHA-256 in PowerShell: `Get-FileHash .\TcgTournamentManager-0.2.3-win64.zip`.
   It must be `D61CDB50EE72B3B3756603207FD54B56A5654F0756E2154F1406B5FF1351767B`.
3. Right-click the ZIP, choose Extract All, and extract everything.
4. Double-click `TcgTournamentManager.exe` in the extracted folder.

Nothing else has to be installed. The program is not code-signed, so Windows may show
"Windows protected your PC" the first time; if the checksum matches, choose "More info"
and "Run anyway". The README inside the ZIP is a short guide for organizers.

## Known limitations

- Scoring and tiebreakers are the club's own settings, not certified by Bandai, The
  Pokémon Company or Wizards of the Coast.
- One-on-one matches can only be reported as a win for one player: there is no way to
  enter a draw on the round screen.
- Players cannot be added once a tournament has started.
- Tested on 64-bit Windows 11 only. English only. One PC and one Windows user; nothing is
  synced. No installer, automatic updates or code signing.
